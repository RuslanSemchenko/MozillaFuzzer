#   Additional Domato rules for modern web APIs that are not covered by js.txt.
#
#   This file is included from js.txt before "!begin lines". The global line
#   guard ("try { <line> } catch(e) { }") set by js.txt is inherited and is not
#   redefined here.
#
#   Sections:
#     * creators for types that js.txt references but does not define
#       (without these the generator raises "No creators for type ...")
#     * event-driven APIs       (EventSource, URLPattern, document PiP)
#     * Encoding API        (TextEncoder / TextDecoder)
#     * WebSocket
#     * Web Crypto          (crypto / SubtleCrypto)
#     * Web Audio           (AudioContext / OfflineAudioContext)
#     * Streams             (ReadableStream / WritableStream / TransformStream)
#     * HTML Sanitizer
#     * View Transitions
#     * Storage Manager / misc
#
#   NOTE: generated code must not contain a bare '<' character, otherwise the
#   Domato tag parser would mistake it for the start of a placeholder.
