# Hand-written stateful scenarios for the DOM/JS block.
#
# The generated webapis.txt can only emit a call when the receiver is obtainable
# in one expression. These lines carry the APIs whose receiver is a *state*: an
# IDB database that only exists inside onsuccess, a MediaSource that only opens
# after a blob URL is attached, a crypto chain, observer callbacks, OPFS handles.
#
# Rules that bite, from AGENTS.md:
# - every line is drawn on its own with replacement, so a line declares and uses
#   its own state; var (never const/let) is the only declaration form.
# - the !lineguard wraps the synchronous part only. An exception inside an async
#   callback aborts that callback, not the line, so each callback body groups its
#   calls in try/catch.
# - no bare `<` / `>` outside comparisons: Domato would read it as a symbol.
#   `<lt>`/`<gt>` are the escape for angles inside generated text.
# - a `#` is a comment marker even inside a string; do not use one.
