#   Firefox-only HTML grammar.
#
#   The generator regex in domato/generator.py turns every literal "<tag "
#   that appears in the generated markup into an id and a typed htmlvar, so
#   each rule below exists to materialise a typed receiver for the DOM/JS
#   rules. Tags that navigate, submit, load external resources, run script or
#   open a plugin are deliberately absent:
#     script, iframe, frame, frameset, object, embed, applet, link, meta,
#     base, title, head, html, body, plaintext, xmp, noembed, noframes,
#     noscript, img/audio/video/source/track with a src.
#   An element without src loads nothing; media elements are here only so
#   HTMLMediaElement receivers exist. A bare iframe has no src (about:blank,
#   no fetch and no navigation) and is here only so HTMLIFrameElement
#   receivers exist.
#
#   MathML used to dominate the page: uniform <element> weights + a recursive
#   mrow/mfrac/msqrt tree (E[children] ~1.05) made ~90% of tags MathML, so a
#   case looked like a wall of formulas and starved HTML/canvas/SVG receivers.
#   Fixes stacked here: HTML-heavy <element> weights, a rare MathML root, and
#   shallow math (operators wrap terminals only — no nested roots/fractions).
#   Canvas is also up-weighted so the body shows the surface the Canvas 2D
#   block is fuzzing (the template appends its own canvas too).
